What happens when you run an evaluation

Django scores the retriever's output. It never makes up retrieval results.

  1. StartPick a dataset, K and a retriever, then run.
  2. Create runAn EvaluationRun record stores the configuration.
  3. Load datasetTest queries and their ground-truth grades.
  4. RetrieveThe adapter collects ranked chunk IDs from your retriever.
  5. MatchRetrieved IDs are matched with the expected IDs and grades.
  6. ScoreSix metric functions run for every query.
  7. AggregateAverages over all evaluated queries.
  8. ReportScores, ranks, missed chunks and failed queries.
